**Beluga 3.2: a leaderboard with your friends, who's on a board, Clone from your GitHub repos, and previews of React Native components.**

- **Leaderboard**: Usage has a scoreboard with your friends, and it holds up when you have many of them.
- **Who's on a board**: a board shows its people beside Active and Backlog, with Add Friend right there.
- **Clone from your GitHub repos**: Clone lists your own repos to pick from, instead of asking for an address.
- **Live previews** draw React Native components, built as their web build would be, and Tailwind 4.1 projects preview again. A Tailwind that won't load says so.
- **Asking for a star, once**: Beluga no longer asks for a coffee. It asks for a GitHub star only at your third merged pull request, in a new sheet with a Share feedback button.
- **The branch pill** sits beside the worktree's name, and is smaller.
- **Beluga's new home**: the app, the updater and the phone now point at github.com/beluga-labs/beluga.
- **Fixes**: fetch and push work with friends who only have SSH, and on the Linux AppImage; Settings' MCP check uses the variables you saved in Settings › Environment, as real runs do, for Claude and Codex; a worktree no longer gets named after an expired sign-in error; Usage's card drops in smoothly on slower GPUs; stats count merged pull requests again; a pasted worktree chip is one piece in the message box and as wide as its name; a deleted image in an answer shows a placeholder instead of an error; a part of the window that fails says why instead of turning grey; on Linux, no GTK shortcut warnings, sound in the AppImage, and pairing says why it failed; restricted Codex sessions on Linux run again.

The phone app is 3.2.0 too, and it updates by itself, now from Beluga's new home on GitHub.

The Android app (`Beluga-3.2.0.apk`) and Beluga Link (`Beluga-Link.apk`) are attached.
