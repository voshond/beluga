**Beluga 3.1: agents from outside Beluga, GitHub Copilot, comments on a diff's lines, and Beluga in Simplified Chinese.**

- **External agents**: a Claude Code or Codex in your own terminal, a local model, or a hosted agent can drive Beluga through one MCP server. Turn it on in **Settings › External agents**, give each agent a pairing code, and it makes ordinary Beluga chats with your own logins. Each agent has its own grant and its own name on what it does; a card asks you for anything that needs a person, and you can stop or revoke any grant on its own. The phone shows what they did and can stop them too.
- **GitHub Copilot** is an agent you can pick, with Copilot Free on Auto. The agent picker is more compact: agents down a rail, one line per model, and thinking effort as one sliding track from Auto to Max. Claude Code keeps itself current, so new Claude models show up without a Beluga update.
- **Comment on a diff's lines**: select lines in a diff and write a comment. Comments wait above the message box as cards and go to the chat together.
- **Worktree links**: copy a worktree's link and paste it in another chat, where it becomes a chip, on the Mac and on the phone.
- **Simplified Chinese**: **Settings › General › Language** offers Follow System, English and 简体中文.
- **Clone a project from its git address** when you add one, and **Fork to My Mac** gets the project onto this Mac first instead of stopping.
- **Earnings from RevenueCat**, next to Stripe's: MRR, subscriptions, trials and new customers for apps sold through the App Store and Play Store.
- **Shared worktrees**: a guest's @claude in a shared worktree is their own agent, and in a friend's worktree @claude says it asks their agent.
- **The room's Chat** is no longer a place of its own: while someone else is in the room, its group chat is the first channel, and the window opens on Overview.
- **Fixes**: friends hear each other in calls again; Ctrl+V pastes on every keyboard layout, and Add projects shows what it did; Quit always ends Beluga, and on Windows it no longer reopens after installing an update; issues and PR comments written in HTML read as GitHub draws them; long titles no longer clip the toolbar's actions; a live preview that can't draw says so in a short note; Copy Image in Share Your Stats works; the Usage pass swings out without being cut off, and stats no longer say "Since Jan 1970"; on Windows, Codex worktree sessions run in its unelevated sandbox.

The phone app is 3.1.0 too, and it updates by itself. It lists your external agents and stops them, shows GitHub Copilot's mark, and draws worktree links as chips.

The Android app (`Beluga-3.1.0.apk`) and Beluga Link (`Beluga-Link.apk`) are attached.
