**Beluga 3.9.0: any ACP agent, Beluga in a phone's browser, naming rules for branches and pull requests, and a calmer start.**

- **Any ACP agent**: add an agent that speaks ACP from Beluga's list, the ACP Registry or a command of your own in Settings › Agent › ACP agents. Its usage card shows its last 7 days, a quiet agent says so, a stuck one ends with the reason, and ending a run ends what it started. Antigravity now comes from that list and follows your project's rules instead of its own global ones.
- **Beluga in a phone's browser**: the browser view fits a phone. The sidebar is a drawer, the panel a full-screen sheet, every target is easy to tap, and Sentinel, plans, Files and Settings each fit one column. On an iPhone the message box stays above the keyboard.
- **Naming rules**: set how branches and pull request titles are named, for every project or just one, in Settings and Project Settings.
- **A calmer start**: while Beluga scans your projects it says "Loading your projects…" instead of looking like a new install, and a slow start stays "Starting Beluga…" for the first minute instead of saying Beluga isn't running.
- **Sidebar and header**: you and Usage share one card at the bottom of the sidebar, with the room in your card. Folded groups stay folded after a restart, the header shows the project's icon beside its name, and the new worktree box remembers its Based on branch for each project.
- **Panel and terminal**: the panel drags wider, the terminal bar has its own Full Size button, terminal tabs are calmer, and a terminal that attaches again no longer types old replies into your shell.
- **Codex**: Compact works on Codex, and Codex's own compactions show the divider.
- **Previews**: SvelteKit components draw in live previews, with `$lib` and `$app` working.
- **Fixes**: a run that works in cycles is no longer cut off 45 minutes after its first background work; a chat keeps Claude in Chrome when its variables hold an Anthropic key; local models sign in for plans; plan merges work with non-ASCII file names and a plan says what went wrong; switching a plan off Step by Step waits for Start; a task another worktree carries follows that worktree; a milestone is as wide as its head; the Traces toggle keeps its width and each tool links to its website; the Files tab says where its files are on disk.

The phone app is 3.9.0 too, with an ACP agent's week on its usage card, and it updates by itself.

The Android app (`Beluga-3.9.0.apk`) and Beluga Link (`Beluga-Link.apk`) are attached.
