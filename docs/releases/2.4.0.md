**Beluga 2.4.0: the desktop app as a client of your Beluga server.**

- **Connect to a server**: on first launch (or Settings › Server) the app can open a Beluga that runs on another computer, at its https address behind your own domain, instead of running one here. Sign in with a join link or your password; you get the app's notifications, clipboard, tray and links instead of a browser tab. Nothing runs on the client. How: [docs/thin-client.md](../thin-client.md).
- **Device reach**: the server's agents can ask a connected client to run a command, send a file or take a screenshot (`run_on_device`, `get_device_file`, `device_screenshot`). Each request opens an approval window on that computer with the exact command, the file's path and size, or the screenshot request; Deny is the default, and closing it or 25 seconds without an answer denies too. Secrets are refused without asking. Screenshots work on Linux (GNOME on Wayland included) and macOS; Windows gets commands and files for now. What it allows and why the server can only ask: [docs/security.md](../security.md#thin-client-device-reach).

The phone app hasn't changed.
