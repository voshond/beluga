# Languages

Beluga's Mac app speaks English and Simplified Chinese. You pick in Settings › General › Language
(Match the System, English or 简体中文); the window reloads in it, and the menu bar follows.

## How it works

English stays the source, in the code, as it is today. Each other language is one catalog,
`packages/mac/src/i18n/<locale>.json`, that maps the English text to that language, gettext style:

```json
{
  "Turn off": "关闭",
  "Save {0}": "保存 {0}",
  "{0} sub-agent{1} at work": "{0} 个子智能体在工作"
}
```

- **Keys are the English exactly as it shows.** `{0}`, `{1}`… stand for what a template literal
  fills in (`` `Save ${name}` `` is `"Save {0}"`). A translation may reorder them or drop one (an
  English plural ending such as `{1}` → `"s"`). A placeholder right after a letter may be empty.
- **The page is translated as it draws** (`i18n/dom.ts`): text nodes and the attributes people read
  (`title`, `placeholder`, `aria-label`, `alt`), looked up when they appear or change, before the next
  paint. Components don't change; a new English string shows in English until the catalog has it.
- **What people and agents write is never translated**: messages and documents (the markdown
  renderers' paragraphs, list items, headings, cells and quotes, under `data-md`), code, editors,
  terminals and fields you type in. Mark anything else that holds someone's words with
  `translate="no"`.
- **Text that never becomes DOM** goes through `t()` from `i18n/index.ts`: notifications, the native
  menus' labels the window sends, dialogs' titles, the tray.
- **The app shell** (`src-tauri/src/i18n.rs`) reads the same catalog for the menu bar and the
  menu-bar menu, and remembers the window's choice so the next launch starts in it. `Info.plist`
  lists the app's localizations and `locales/zh-Hans.lproj/InfoPlist.strings` translates macOS's
  permission prompts.
- English windows load no catalog at all.

## Adding or updating translations

```bash
node scripts/i18n-extract.mjs --missing --locale zh-CN
```

lists the English the code can show that the catalog doesn't have yet, with where it is. Add each
to the catalog (keep the placeholders). Not everything listed reaches the screen (prompts written
for agents, log lines): leave those out. `tests/i18n.test.ts` checks every catalog uses only its
English's placeholders and covers the menu bar.

A new language is a new `<locale>.json`, a line in `LOCALES` and `resolveLocale` (`i18n/index.ts`),
its loader in `loadLocale`, and its `.lproj` folder.
